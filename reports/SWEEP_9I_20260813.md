## 一、为什么开这张卡

9H 结束时的状态（最小止损 0.5%、方向过滤关闭、365 天 107 笔）：

```
分批毛 +0.17R    成本 0.16R    分批净 +0.00R
```

三个杠杆的账：

| 杠杆 | 结论 |
|---|---|
| 大 R（最小止损 0.5%） | ✅ 已验证有效，成本 0.31R → 0.16R |
| 方向/环境过滤 | ❌ 已证伪，排序在两次测量间翻转，判定过拟合 |
| **限价进场** | ← 本卡，唯一剩下的，量级最大 |

成本算术：`成本(R) = 2 × 单边费率 × 入场价 ÷ R`

```
taker 0.05%/单边  → 0.16R
maker 0.023%/单边 → 0.074R      降幅 54%
```

## 二、核心设计：三组并行统计

**限价进场改变的不只是成本，还有样本构成。** 未成交的信号从盈亏统计里消失，
而**它们不是随机消失的** —— 只在价格回踩时才成交，意味着系统性地偏向某一类行情。
若不记账，会得出方向未知的假结论。

因此每个确认信号都**同时**模拟两条路径，统计输出三组：

| 组 | 内容 | 作用 |
|---|---|---|
| **A 限价成交** | 路径 L 成交的信号，maker 费率、限价 R 结算 | 实验组 |
| **B 限价未成交** | 路径 L 未成交的信号，但**显示其在路径 M 下的结果** | 判断漏掉的是好单还是坏单 |
| **C 全市价基线** | 全部信号走路径 M，taker 费率 = 9H 口径 | 对照组 |

判定逻辑：

- **B 明显优于 A** → 限价漏掉的是好单，省下的成本被吃掉，需重新权衡挂单价位
- **B 明显劣于 A** → 限价同时降成本和筛掉坏单，双重收益
- **A ≈ B** → 纯成本收益，按算术预期兑现

**三组同时显示在面板上，不靠切换参数分别测。** 这是 9H 的教训：反复切配置分别测，
既分不清是哪个改动起作用，不同次测量的样本也可能不一致。

## 三、限价规则（实现细节）

以 C-多为例，C-空完全镜像。

**信号确认时**：

```
R_market = 确认K收盘价 − 止损价              ← 确认时唯一已知的 R
挂单价   = 确认K收盘价 − 限价回撤R × R_market
```

挂单价若 ≤ 止损价则该信号判为**限价无效**（触发即止损，无意义），单独计数显示。
`限价回撤R ≥ 1.0` 时必然发生，参数说明中已警示。

**成交判定**：从确认K的**下一根**开始，最多 `限价超时` 根。

```csharp
if (since < 1) continue;                        // 确认K自身不参与
if (since > LimitTimeoutBars) { 记为未成交; }
bool touched = isLong ? c.Low <= LimitPrice : c.High >= LimitPrice;
```

- **从下一根开始**：确认K的低点在信号成立**之前**就已形成，用它判成交是前视偏差
- **用 Low/High 而非收盘价**：挂单在盘中被触及即成交，不需要收盘价穿过

**成交后重算**（注意 R 变了）：

```
入场价  = 挂单价
止损价  = 不变（仍是 扫除最低点 − 止损缓冲 × ATR）
R_limit = 挂单价 − 止损价                    ← 比 R_market 小
TP1     = 入场 + TP1倍数 × R_limit           ← 随 R 重算
TP2     = 不变（仍是对侧池位），但以 R_limit 计的倍数变大
```

**成交当根即可结算**：填单那根K本身也参与止损/目标判定，采用与市价路径相同的
保守规则（同一根K同时触及止损与目标时按止损计）。

### ⚠ R 变小会部分抵消 maker 的优势

`成本(R) = 2 × 费率 × 价格 ÷ R`，R 变小则分母变小、**成本占 R 的比例上升**。

以 9H 的实测均值估算（入场 ≈ 63700，R_market ≈ 398 即 0.625%）：

| 口径 | R | 成本 |
|---|---|---|
| 市价 taker 0.05% | 398 | 0.160R |
| 限价 maker 0.023%，回撤 0.3R | 398×0.7 = 279 | **0.105R** |

即实际降幅约 **34%**，而非只看费率差得出的 54%。**净期望的算术预期应为
`+0.17R − 0.105R ≈ +0.065R`，而不是 +0.10R。** 真实值以面板实测为准 ——
这正是必须测而不能只算的原因之一。

## 四、新增参数（分组「8 限价进场」）

| 参数 | 默认 | 说明 |
|---|---|---|
| 进场模式(0市价/1限价) | 1 | 只影响画线；三组统计始终全算 |
| 限价回撤(R) | 0.3 | 挂单价距确认收盘多少个R，必须 < 1.0 |
| 限价超时(根) | 3 | 挂单等待的M5根数 |
| taker费率(%,单边,含滑点) | 0.05 | 原「单边成本」移入本组并更名 |
| maker费率(%,单边) | 0.023 | 限价组成本计算用 |

费率做成参数：交易所费率随等级变动，写死会让成本计算失真。

## 五、绘制

- 限价模式下入场线画在**挂单价**
- 已成交：实线，标 `限价成交`，R 与盈亏比按 `R_limit` 显示
- 未成交/挂单中：**虚线 + 半透明**，标 `未成交` / `挂单中`，且不画止损与目标线
  （避免与真实成交的信号混淆）
- 限价无效：按市价口径画，标 `限价无效`

## 九、实测结果（2026-08-13，365 天 M5，最小止损 0.5%，方向过滤 0）

```
全图累计：确认 107 个 / 作废 2185 个
进场模式：市价　挂单回撤 0.3R　超时 3 根　maker 0.023% / taker 0.05%
限价成交：已结 60 笔  成交率 56%(60/107)  触及TP1 45%(27)  到达TP2 18%(11)  全进全出 -0.05R  分批 +0.17R  成本 -0.10R  分批净 +0.06R
限价未成交：47 笔（按市价口径结算）  触及TP1 57%(27)  到达TP2 43%(20)  全进全出 +0.55R  分批毛 +0.57R
全市价基线：已结 107 笔  触及TP1 45%(48)  到达TP2 29%(31)  全进全出 +0.05R  分批 +0.17R  成本 -0.16R  分批净 +0.00R
```

### 9.1 两项自检均通过

| 自检 | 结果 |
|---|---|
| **样本记账** | `确认 107 + 作废 2185 = 2292`，与 9H 完全一致 ✓ 限价确实只改入场方式 |
| **成本算术** | 限价组成本 **0.10R**，落在预估上界 0.105R 内 ✓ R 确实缩小并抵消了部分 maker 优势 |

C 组（全市价基线）为 `分批净 +0.00R`，与 9H 的 +0.00R **逐位相同**，
证明市价路径未被本卡改动。

### 9.2 结论：落在 §二 判定逻辑的最坏一档 —— 限价漏掉的是好单

| 组 | 笔数 | 到达TP2 | 分批毛 | 成本 | 分批净 |
|---|---|---|---|---|---|
| A 限价成交 | 60（成交率 56%） | **18%** | +0.17R | 0.10R | **+0.06R** |
| B 限价未成交 | 47 | **43%** | **+0.57R** | —（若走市价则 0.16R） | 市价口径 **+0.41R** |
| C 全市价基线 | 107 | 29% | +0.17R | 0.16R | +0.00R |

**B 组的 TP2 命中率是 A 组的 2.4 倍，分批毛是 3.4 倍。**

反推 A 组信号在**市价口径**下的表现：

```
(107 × 0.17 − 47 × 0.57) / 60 = −0.14R
```

即：**会回撤 0.3R 的信号本身就是坏的（市价 −0.14R），不回撤的才是好的
（市价 +0.57R）。限价单精确地只买到了坏的那一半。**

加权自洽校验：`(60×18% + 47×43%)/107 = 29%` = C 组 TP2 命中率 ✓
说明 18% 与 43% 的差距是**纯选择效应**（TP2 是同一个价格、同一个判定），
不是 R 缩放造成的假象。

### 9.3 为什么必然如此 —— 9G 的数据早就写着答案

9G §4.2 测过每笔的最大浮亏：**赢单的最大浮亏只有 0.01R**。

**成功的扫除反转根本不回头。** 确认之后直接走掉，所以挂在 0.3R 下方的单子
永远等不到；愿意回踩 0.3R 的，本来就是动能不足、正在挣扎的那批。

这不是巧合，而是本 setup 的内在性质：**它的好单在结构上就是"买不到更好价格"的。**
限价进场与这套逻辑天然不兼容，调挂单价位改变不了这个方向 —— 挂得浅则成交率高
但省不下成本，挂得深则更彻底地只买到坏单。

**因此 §六 的参数扫描（限价回撤 0.15/0.3/0.5/0.8、超时 2/3/5）不再执行**：
扫描的前提是"存在一个使 A 优于 B 的挂单位置"，而 9.3 说明该前提不成立。
继续扫描只会在同一份数据上反复切片、制造过拟合的假最优值 —— 这正是 9H §9.3
的教训。

### 9.4 统计显著性

| 对比 | 差值 | 标准误（`1.5R/√n`） | 判断 |
|---|---|---|---|
| A `+0.06R`(n=60) vs C `+0.00R`(n=107) | 0.06R | 0.19R / 0.15R | **在噪声内，不显著** |
| B `+0.57R`(n=47) vs A市价 `−0.14R`(n=60) | **0.71R** | 0.22R / 0.19R | **约 2.5σ，真实效应** |

**限价省下的成本带来的 +0.06R 改善不显著；但「是否回撤」这个选择效应是显著的。**

### 9.5 R 变小对成本的实际影响（§三警示项的实测值）

| 口径 | 成本 | 说明 |
|---|---|---|
| 市价 taker 0.05% | 0.16R | 9H 基线 |
| 限价 maker 0.023% + 回撤 0.3R | **0.10R** | 实测 |
| 若只按费率差计算（错误算法） | 0.074R | 忽略了 R 缩小 |

实际降幅 **37.5%**（0.16 → 0.10），而非只看费率差得出的 54%。
立项时卡片预期的 `+0.00R → +0.10R` 因此偏乐观，
修正后的算术预期为 `+0.17 − 0.10 = +0.07R`，与实测 +0.06R 吻合。

## 十、9I 结论

1. **限价进场这条路走不通。** 按 §二 判定逻辑落在「B 明显优于 A」一档：
   省下的成本被选择性偏差吃掉，且改善（+0.06R）在噪声内。
   **建议 `进场模式` 保持 0（市价）。**
2. **参数扫描不执行**，理由见 9.3 —— 前提不成立，扫描只会制造过拟合的假最优。
3. **但本卡测出了一件比结论更有价值的事**：B 组 47 笔、市价口径净 **+0.41R**。
   这证明**信号本身有真实边际**，只是被「必须对全部 107 笔付全额成本」稀释成
   +0.00R。**问题从来不是信号质量，而是没办法只做好的那一半。**
4. **而区分好坏的变量（是否回撤 0.3R）只有入场之后才知道**，无法事前利用。
   任何试图事前预测它的做法都需要新的证据支撑，且过拟合风险极高。

### 三卡合并结论（9G / 9H / 9I）

| 杠杆 | 结果 |
|---|---|
| 调参（穿透、容差、周期） | ❌ 天花板 −0.015R |
| 换周期（M15） | ❌ 无关变量，实测更差 |
| 筛大 R（最小止损 0.5%） | ✅ 有效，−0.19R → +0.00R |
| 方向/环境过滤 | ❌ 排序在两次测量间翻转，过拟合 |
| 限价进场 | ❌ 漏掉好单，改善在噪声内 |

**最终配置**：最小止损 0.5%、方向过滤 0、进场模式 0（市价）、分批离场
（TP1 减半仓 + 移保本），**净期望 +0.00R**。

**用途结论维持 9G**：不作独立开仓系统；作为**择时辅助**使用时不产生额外开仓
成本，`+0.17R` 的分批毛边际即为净收益。
